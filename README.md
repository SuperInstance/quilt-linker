## What is this?
`quilt-linker` is a substrate walker for graph-based substrates, enabling substrate-to-substrate linking across a fleet. It provides operations to find links, resolve paths, and compose chains, adhering to the polarity rules of ACCEPT, DRIFT, and REFUSE.

## Doctrine
`quilt-linker` embodies the doctrine that *cells-are-scars*, where each resolved node or edge represents a permanent mark in the substrate’s history. The *witness-log-is-prediction* doctrine is upheld through its SHA-256-witnessed chains, ensuring every operation is verifiable and future-interpretable. It grows the substrate incrementally, treating links as living structures rather than static mappings, and embraces polyformalism by supporting diverse substrate representations.

## Polarity rules
| Polarity | Condition | Outcome |
|----------|-----------|---------|
| ACCEPT   | Link is valid and unique | Chain grows, receipt issued |
| DRIFT    | Link is ambiguous or conflicting | Chain pauses, witness logged |
| REFUSE   | Link is invalid or malicious | Chain aborts, error raised |

## Operations
| Operation | Description |
|-----------|-------------|
| `find_links` | Discovers potential links between substrates |
| `resolve` | Validates and commits links to the substrate |
| `compose_chains` | Merges resolved links into a verifiable chain |

## Architecture
`quilt-linker` operates on a canonical envelope consisting of an 8-field receipt, ensuring every action is traceable. Chains are SHA-256-witnessed, providing a cryptographically verifiable log of all substrate interactions.
